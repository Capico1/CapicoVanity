Capico 靓号分享版（Windows 64 位） · Capico（X：@NanaWiti）

双击 CapicoVanity-Win64-*.exe 即可启动，无需安装开发工具或以管理员身份运行。
需要 .NET Framework 4.7.2 或更高版本。
分享版启动器会先检测运行环境；已安装 4.7.2、4.8 或更新的 4.x 时可直接继续。
缺少时会提示是否打开微软官方下载页面，请选择 Runtime（运行时），无需 Developer Pack。
安装结束后重新打开本程序；若安装器要求重启，请先重启。程序不会自行下载或安装运行时。
运行环境检测无需联网，用户选择打开下载页面时才会启动默认浏览器。
第一次打开会将程序释放到 %LOCALAPPDATA%\NanaVanity\Programs\版本标识\。
配置和生成的钱包保存到 %LOCALAPPDATA%\NanaVanity\Data，与程序缓存分开。
主程序目录内的 jmsTools.exe 也可以直接运行。

地址余额查询仅使用公开 RPC，显示 ETH、BNB、SOL 原生币余额，无需 API Key 或 Secret Key。
“找回自己的钱包”是独立标签页；验证成功的结果可在“命中列表”查看。
找回结果仅保留在本次会话中。结果页和命中列表默认隐藏助记词、私钥；复制公开信息不会带上它们。
如需备份，请在命中列表右键单独复制，确认后只粘贴到可信的钱包或加密备份。其他程序仍可能读取系统剪贴板。
钱包找回默认优先使用 OpenCL GPU，找不到可用设备或 GPU 无法运行时改用多线程 CPU。也可选“仅 CPU”并设置线程数。
使用 GPU 找回时，批次默认自动优化；取消勾选可手动设置。运行中改用 CPU 时会从头搜索，避免跳过候选。
公共节点可能因网络、配额或限流而失败，可在节点设置中更换。
BSC 预置的 binance.org 是公共 RPC 地址，不需要币安账户或 API Key。

没有包含发布者的 API 配置、钱包、私钥记录或本机 GPU 配置。
靓号生成默认优先使用 GPU，检测不到兼容设备或 GPU 无法运行时自动改用多线程 CPU。也可以直接选“仅 CPU”。
EVM 靓号生成的 GPU 加速需要计算能力 7.5 以上（含 7.5）的 NVIDIA 显卡和兼容驱动。GPU 批次默认自动优化，结果按显卡、驱动和引擎缓存。
SOL 靓号生成和钱包找回的 GPU 加速需要可运行本程序计算内核的 OpenCL 显卡及驱动。CPU 模式无须 CUDA 或 OpenCL。
SOL 靓号生成可选择“自动优化（推荐）”，会按显卡、驱动和内核版本保存调优结果。
首次使用需要编译和调优，再次生成会复用 GPU 资源；手动批次设置仍然可用。
SOL 显示的地址/秒包含搜索过程中的批次准备、传输和等待，总用时另计初始化。
新生成的钱包和导出文件属于本机使用者，请自行保存。
靓号钱包使用 Windows DPAPI（当前用户）加密保存；文件不再包含明文私钥。
打开或刷新“已生成靓号”时，程序会校验并就地加密当前目录及 Deleted 中的旧明文钱包；失败的原文件保留。
只有明确显示或复制时才解密。加密文件依赖原 Windows 用户配置，不能当作可跨电脑恢复的备份。
换电脑或重装前，请用原账户复制所需私钥并保存在自己控制的加密备份中；不要分享明文私钥或旧备份。

靓号生成支持固定前后缀与模板模式，可选择模板匹配地址头部或尾部。
AAAA 表示四位相同字符（例如 7777）；ABCDE 表示五位递增顺子（例如 23456、abcde）。
下拉列表提供 54 个模板：3–12 位相同、3–10 位递增/递减，以及交替、成对、循环和对称组合。
例如 ABCABC、AABBCC、AAABBB、ABCCBA、ABCDEFFEDCBA，也可手动输入 3–12 位重复规律。
同字母代表同字符，不同字母代表不同字符；无重复字母时仅支持递增/递减顺子，顺子不跨数字和字母。
例如 ABCA 可匹配 7b37，AABAAB 可匹配 77b77b；更长且重复约束更多的模板通常需要更久。
SOL 会遵循有效 Base58 字符，大写 I、O 和小写 l 不属于有效字符。
停止条件可选：找到 1 个停止、找到指定数量停止、持续生成直到手动停止。
每个完成的结果都会独立校验并自动保存到“已生成靓号”，本轮计数按成功保存的数量显示。
列表最多显示最近 5000 条，全部文件仍保留在钱包保存文件夹。
模板、位置及停止偏好会在再次打开同一版本时恢复。
模板模式可点“附加模板”，勾选或输入最多 5 个组合，例如 AABBAABBAABB。
附加模板使用与主模板相同的头尾位置和大小写设置。命中任意选中模板都会计入本轮保存数量。
CPU 和 SOL GPU 对每个候选同时匹配主模板和附加模板；EVM GPU 在各模板间轮流搜索，会分走主模板的搜索时间。
8 位相同已包含 9 位及以上，匹配结果显示实际连续长度。一个钱包命中多个模板时仍只保存一份。

EVM 和 SOL 的固定前后缀、模板搜索均按当前引擎实测速率显示搜索时间估算。CPU 通常更慢，建议先用较短的条件试跑。
找到 1 个时显示约 50% 命中时间；指定数量时显示剩余数量的平均搜索时间；持续生成只估算下一个。
估算不含初始化和保存，不是倒计时；停止或完成后显示本轮实际用时。
SOL 的 Base58 头部偏差可能较大，EVM 模板按随机展开的平均难度粗估。

分享时可只发外层 EXE，或发送包含 EXE 和此说明的 ZIP。

普通版：默认不包含可选 CUDA 二进制，EVM 使用 CPU，SOL 仍可自动使用 OpenCL。需要 CUDA 版时应通过 -IncludeCuda 重新打包，不要向已解压程序缓存添加 DLL。
分享版数据目录：%LOCALAPPDATA%\NanaVanity\Data；程序缓存：%LOCALAPPDATA%\NanaVanity\Programs。每次启动核对所有程序文件，篡改或额外文件会阻止启动；不会删除钱包。旧版本数据不会自动搬移或删除。
找回页面的助记词模板默认隐藏，可明确勾选“显示”；开始搜索后自动恢复隐藏。
